MORVAN HUB V1 — INTÉGRATION SUPABASE

1. Installer Node.js 22 (22.12 ou ultérieur pour le socle optionnel).
2. Ouvrir un terminal à la racine de ce dossier et lancer : npm ci
3. Copier .env.example vers .env.local et renseigner l'URL Supabase
   et sa clé publique publishable. Ne jamais utiliser service_role.
4. Lancer : npm run dev
5. Ouvrir http://localhost:5173/index.html pour Explorer,
   et http://localhost:5173/pro.html pour Pro.

Aucun projet Supabase n'existe encore : le code ne suffit pas à créer
la base. SUPABASE-INTEGRATION.md décrit la création, les migrations,
les rôles et la configuration Auth nécessaires.
Sans configuration, les écrans l'indiquent explicitement.
