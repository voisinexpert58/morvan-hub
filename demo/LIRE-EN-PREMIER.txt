BOURGOGNE EXPLORER ET BOURGOGNE PRO — V1

Les entrées utilisent maintenant le client Supabase et nécessitent Vite.
Le serveur Python historique ne permet pas de compiler cette intégration.

Depuis le dossier parent : npm ci puis npm run dev.
Explorer : http://localhost:5173/index.html
Pro : http://localhost:5173/pro.html

Lire ../SUPABASE-INTEGRATION.md avant de configurer un projet Supabase.
Le fichier ../.env.local contient seulement l'URL et la clé publique.
Aucune clé service_role ni clé secrète ne doit entrer dans le navigateur.

Les anciens modules fictifs restent dans core/ et modules/ comme exemples.
Le catalogue fictif d'Explorer n'est utilisé que si VITE_DEMO_MODE=true
et qu'aucune configuration Supabase n'est renseignée.
